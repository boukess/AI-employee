# FRBouK editing assets
8 original reaction meme cards (PNG), 8 transparent overlays (PNG), 6 abstract backgrounds (PNG), 6 cut demos (GIF), 6 transitions (72 alpha PNG sequence frames + 6 GIF previews), 5 original synthesized sounds (WAV), and 5 font-style recipes.
Use vertical assets on 1080x1920 and horizontal assets on 1920x1080 timelines. Reaction cards are 1080x1080; use as inserts or overlays.
PNG images import directly. Import each transition as a 30fps image sequence. If your editor cannot import sequences, use an image-sequence-capable compositor to render alpha video first. GIFs demonstrate timing; they are not editor effect presets.
J/L-cut GIFs label the audio overlap visually; they do not contain audio.
SFX are mono 48kHz WAV; mix below speech, and audition impact levels.
The font download failed, so official font links and exact style recipes are included. Font files are not bundled. Preview typography uses Arial.
All timelines below and in the reference pack are proposed FRBouK recipes, not measured analyses of the linked creator videos.
