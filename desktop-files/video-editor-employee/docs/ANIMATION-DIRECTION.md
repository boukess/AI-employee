# Same style, new content

Read STYLE-SPEC.md first. Create graphics from the current video's transcript while retaining the corpus's visual grammar. The goal is for a new video to belong to the same series.

For each spoken beat, select a relevant reference and record which traits you are preserving: presenter composition, compact graphic scale, thin UI borders, white/cream space, short typography, staged reveal and timing. Then draw the needed objects and animate their relationship. For “Chat and Cowork become one,” create two small app panels that merge into a single interface inside those same bounds. Do not turn it into a dark full-screen production dashboard or add a new headline system.

Use the shared elements as building blocks, not as a fixed set of complete animations. Custom scene code can build new diagrams, interfaces, logo treatments, flows and transitions without changing the style. Screenshots supplied by the user can be used where the corpus uses real UI. Otherwise use clearly illustrative artwork and avoid fabricated product evidence.

Fresh animation does not mean a new palette, font system, presenter layout or overall look.

Implementation references: [Remotion alpha rendering](https://www.remotion.dev/docs/transparent-videos), [FFmpeg filters](https://ffmpeg.org/ffmpeg-filters.html), and the installed Resolve scripting API. The corpus itself is the creative authority.
