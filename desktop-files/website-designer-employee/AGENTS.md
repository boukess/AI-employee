# Website Designer workspace

For website work, read [scene-website-director/SKILL.md](scene-website-director/SKILL.md). It is the authoritative employee workflow; follow its references as needed.

Continue in the member's specified website project. For a new site without a specified location, use `member-projects/<brand-slug>/`. Read that project's brand, design, asset, QA, and status records before later edits. Keep private notes outside the publishable `dist/` or equivalent directory.

The library, starter, templates, and employee instructions are shared kit materials. Copy needed starting material into the member project. Preserve existing websites and unrelated work; edit the shared kit itself only when the task asks to maintain it.
