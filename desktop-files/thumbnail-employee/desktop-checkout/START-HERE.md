# Your AI Thumbnail Employee

Give this employee your channel or niche once. It builds a thumbnail reference
library around your content, then uses that library to turn a transcript, topic,
or working title into an original thumbnail.

## Start in ChatGPT

1. Attach `AI-Thumbnail-Employee.zip` to a chat with image generation and web research available.
2. Paste the Start prompt below.
3. If ChatGPT cannot read the ZIP, unzip it and attach `CHATGPT-STARTER.txt` instead.
   That file includes the complete employee instructions. You can paste its text
   if file attachment is unavailable.
4. Answer the brief interview. You can share a YouTube, Instagram, or TikTok link,
   or describe your niche if you do not have an account yet.

A ChatGPT Project is useful for keeping the instructions and your saved library
together. Attach portraits and other important visual references as individual
images when requested; an image inside a ZIP may still need to be attached separately.

## Start in Codex

1. Unzip the download and open the extracted `AI-Thumbnail-Employee` folder as your project.
2. Paste the Start prompt below. Codex can read this folder's `AGENTS.md`.
3. Use a session with web research, image viewing, and built-in image generation.

If your Codex interface accepts a ZIP attachment, you may attach it and ask Codex
to extract it into a new project folder first. In the terminal, unzip it, change
into the extracted folder, and start Codex there. Dropping a ZIP into a terminal
may only insert its path; it does not start the employee by itself.

## Start prompt

> Start my AI Thumbnail Employee. Read START-HERE.md and thumbnail-designer/SKILL.md from the attached package or open project. If I attached CHATGPT-STARTER.txt, use that self-contained guide instead. Check which files and tools you can access, then begin my creator interview. Use relevant context or memory already available to you, and ask me only for what is missing.

## What happens next

- **A short interview.** Your niche, audience, channel, and creative preferences.
  A competitor list and a photo of yourself are optional. Person-free thumbnails work too.
- **Your reference library.** The default goal is 300 unique, visually reviewed
  thumbnails across 20 creators and five topic groups where suitable material is
  available. Larger libraries may take multiple sessions. The employee reports
  real coverage and saves progress. You can request a smaller starter library or
  an expanded 500+ reference library.
- **Your first thumbnail.** Send a transcript, topic, or title. The employee
  chooses a direction, prepares its image prompt, and generates a thumbnail.
- **Accurate assets when needed.** For a face, logo, real interface, or specific
  object, you can provide an image, ask the employee to find a public reference,
  or omit an optional element. It cannot find a private screen or reconstruct
  your likeness from memory alone.

You do not need to manage code or install Python. The included helper is optional
and is for the employee to use when the environment supports it.

## Come back later

In Codex, reopen the same project folder. In an upload-only ChatGPT session,
download the updated workspace ZIP or checkpoint the employee provides. Keep it
with your instructions and attach it next time. Ask:

> Resume my AI Thumbnail Employee from this saved workspace. Tell me where my library stands, then help with my next thumbnail.

Reference images supplied through temporary links may need to be attached again.
Keep your personal workspace separate from the original community download.

## A few practical limits

Tool availability and usage limits vary by account and session. The employee will
identify an unavailable tool and continue the parts it can do. It will not describe
a written prompt as a finished image. A ZIP is a collection of instructions and
files, not an installer or an automatically running application.

The library supplies examples and design evidence at generation time. It does not
fine-tune or retrain ChatGPT. Public view counts do not reveal thumbnail CTR, and
no thumbnail workflow can promise a particular number of views.
