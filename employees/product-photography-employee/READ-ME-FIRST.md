# AI Product Photography Employee

Turn a product photo into a studio-style product image in ChatGPT or Codex.

## Start in ChatGPT

1. Attach the downloaded ZIP to a conversation that can create images.
2. Say **“Go”** or **“Set this up so I can start using it.”**
3. Confirm your brand, then upload a clear photo of your product when asked.

If ChatGPT cannot open the ZIP, unzip it and upload **START-HERE.txt** instead. It contains the complete employee, including its photography guide. You can also paste that file's contents into the conversation. Upload your product as an image attachment so the image tool can see it.

## Start in Codex

Attach the ZIP if your interface supports it and say **“Go.”** If attaching an archive is unavailable, unzip it, open the extracted **AI-Product-Photography-Employee** folder as your Codex workspace, and say **“Go.”** The folder includes workspace instructions and a local skill. No terminal commands, API key, or global installation are needed for the built-in image workflow.

If Codex needs a more explicit instruction, say:

> Read START-HERE.txt and start the AI Product Photography Employee onboarding.

## What happens next

The employee asks which brand to work on. When relevant memory or project context is available, it may suggest a brand for you to confirm. Otherwise, it asks for the brand name and what you sell. You can use it without an established brand.

After you upload a product photo, it chooses a studio setup suited to the product's material and shape, creates one image, and checks for visible product changes. A phone photo is fine: include the whole item, keep it in focus, and make the front label or important details readable. Add another view if you need an angle that the first image does not show.

The default is a clean square studio hero image. You can request a different look in ordinary language:

- “Use a warm cream background.”
- “Make this a premium dark studio shot.”
- “Keep this lighting for the next product.”
- “Make a vertical version with space above for a headline.”
- “The cap changed. Restore the cap from my original photo.”
- “Switch brands.”

## Keep using it

Continue in the same conversation for the simplest experience. Say **“Save my brand profile”** for a reusable summary. In ChatGPT, download or copy that summary and attach it with the employee in a future chat. In a writable Codex workspace, the employee keeps local brand and shoot notes as work progresses.

## A few practical limits

This package supplies instructions and photography knowledge; your session supplies image generation. Tool availability and usage limits depend on your account and environment. Uploading the package does not install a model, enable a missing tool, or grant access to all your chat history.

AI edits can change fine print, logos, color, and small features. Review these against your original before publishing. If you need exact packaging pixels, tell the employee; it will explain what its available editing tools can preserve and avoid promising an exact match from generation alone.
