# How your employee works

SCENE combines a decision process with editable source. It learns the brand, chooses an appropriate visual approach, creates the actual website, and tests what a visitor sees and can do.

## Two sources of visual foundations

The offline library contains five original single-file scenes: Orbit Sculpture (WebGL), Product Stage (CSS 3D), Spatial Gallery (CSS perspective), Kinetic Type (2D motion), and Architectural Light (SVG depth). Each makes its actual technique clear.

The separate cinematic workbench is a complete Three.js site with scroll-driven scenes, an original glass employee-file composition, semantic content sections, reduced-motion behavior, and a fallback illustration. The employee should adapt its visual subject and structure to the brand. It is not the right default for every business.

## What makes it an employee

`scene-website-director/SKILL.md` routes discovery, design, implementation, and review. Supporting references give the agent a focused procedure when each phase is needed. The project templates keep facts, decisions, asset sources, test evidence, and unfinished work available for future sessions.

Your coding agent provides execution, file editing, available browsing tools, and any hosting integration. The kit supplies the reusable instructions and original starting material. The optional local MCP bridge simply searches and retrieves the five single-file library entries; it neither builds nor publishes websites.

## Extending the library

Add an original standalone HTML file inside `library/layers/`, register it in `library/catalog.json`, and run `node scripts/build-library.mjs` from the kit root. Preview and review the new scene before distributing it. Keep multi-file starters under `starters/` with their own setup and license records. Do not place a multi-file build in the single-file MCP catalog.

Keep provenance and technique labels accurate. A composition can use CSS or SVG for dimensional depth without using a true 3D renderer. Visual quality depends on composition, typography, relevant assets, readable content, motion, and iteration—not a library name alone.
