# Worked example: AI Employee Lab

Two steps of the AI Ad Copywriter, run for a real business: AI Employee Lab, a $9/month Skool community that ships ready-built AI employees.

When a member says "show me the example", walk them through these files in order.

| Step | File | What it shows |
|---|---|---|
| 1. Interview | `brand.md` | The brand file the interview produces |
| 4. Creative | `creatives/split-demo.mp4` | The video ad itself |
| 4. Creative | `creatives/_frames/split-demo/sheet.jpg` | The contact sheet `creative.py` builds from a 47-second founder demo video |
| 4. Creative | `creatives/_frames/split-demo/transcript.txt` | The transcript, with timestamps |
| 4. Creative | `creatives/split-demo-read.md` | The creative read the copywriter writes before it writes any copy |

The research (`corpus/`) and the finished copy (`copy/`) depend on each member's own niche, so they come from the member's own run. `docs/3-study.md` and `docs/5-write.md` show the exact shape of those files.
