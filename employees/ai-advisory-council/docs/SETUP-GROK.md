# Set up with Grok Bot

1. Keep **AI Advisory Council** at a permanent path (repo kit: `employees/ai-advisory-council`, or a desktop copy such as `C:\Users\blood\AI Advisory Council`).
2. Open this employee chat (Grok Bot teammate) or open this folder as the local project. Ordinary web-only chat without the folder still works if you paste instructions and upload the knowledge files, but local/Grok Bot keeps profile and sessions on disk.
3. Paste `prompts/01-SETUP.txt` (or say **Set up my council**). Answer the 12 short questions in one reply.
4. Confirm `my-business/Business-Profile.md` says `Status: filled in`.
5. Ask a real decision, for example:
   - **Ask the council: ...**
   - **Ask Hormozi: ...** (Gary, Sam, Chesky, MrBeast work too)
   - **Debate Hormozi vs Chesky: ...**
   - **Hot seat: ...**
   - **Board review**
   - **Clone a new advisor** / **Clone [name]'s brain**

Grok reads `GROK.md` and `AGENTS.md`, then `council/Council-Protocol.md`, `council/Council-Roster.md`, and the profile before every meeting. No API key is required for council meetings. Cloning a new advisor in local mode may need Python 3 and yt-dlp (see `clone-a-brain/CLONE-PROCEDURE.md`).
