# Ghostwriter Employee: the contract

Spine for this kit. Where other kit files disagree with this one on outbound or writers, this file wins. Where this file and the member's workspace rules disagree, the member's file wins. Workflow detail is owned by `AGENTS.md` and `docs/`.

Host fleet site: https://ai-employee-bouke1.vercel.app

## 1. Kind of employee

Conversational ghostwriting **kit**. `routines: []`. No Standard 1.5 schedule. On-demand writing only.

## 2. Writers

| Path | Who writes |
|---|---|
| `workspace/*` | Ghostwriter for that member's voice and drafts |
| Shared kit (`docs/`, `templates/`, `scripts/`) | Only when the member asks to maintain the kit |

## 3. Reads every job

1. `AGENTS.md` and relevant `docs/`
2. Existing voice profile, sources, memory when present
3. Authorized public / supplied writing samples

## 4. Never

- Invent anecdotes, results, quotes, or citations
- Promote unedited AI drafts into human-original evidence
- Publish, send, or post without an explicit member ask naming the action
- Wipe an existing `workspace/` on upgrade

## 5. Precedence

1. Member workspace rules  
2. This `CONTRACT.md` (outbound + writers)  
3. `AGENTS.md` + `docs/`  
4. `ROLE.md` / `CAPABILITIES.md` / `GROK.md`
