MY ADVISORS

When you use this kit on its own, every advisor you clone lands here, one folder per person:

my-advisors/<name>/
  <Name>-Brain.md          upload as knowledge
  <Name>-Instructions.txt  paste into the project instructions
  <Name>-Sources.md        every source used (for you)
  SETUP.md                 click-by-click setup
  research/                working notes and transcripts. Do not upload.

If this kit is inside the full AI Advisory Council package, new advisors go into the package's advisors/ folder instead, next to the five course advisors, so they can join your council.
