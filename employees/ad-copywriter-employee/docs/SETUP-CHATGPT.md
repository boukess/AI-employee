# Setup: ChatGPT

You need a ChatGPT plan that lets you upload files (Plus or higher works best).

## 1. Start a chat

1. Open ChatGPT and start a new chat.
   Optional: create a **Project** called "Ad Copywriter" and start the chat inside it. That keeps everything in one place.
2. Upload the **AI Ad Copywriter.zip** file you downloaded. Don't unzip it.

## 2. Paste the kickoff prompt

Copy this and send it with the zip:

```
I uploaded the AI Ad Copywriter zip. Unzip it with your Python tool to /mnt/data/ai-ad-copywriter/, read AGENTS.md completely, and follow it exactly. You are running in ChatGPT, so follow the ChatGPT notes in AGENTS.md. If I also uploaded a workspace zip from an earlier session, unzip it into the workspace folder first.

go
```

(The same text is in `prompts/chatgpt-go.txt`.)

## 3. Answer the questions

It interviews you first. For the research step, it gives you Ad Library links. Open each one, scroll down a few times, select all (Cmd+A or Ctrl+A), copy, and paste the page back into the chat. If you're in Agent mode, it may open the pages itself.

Then upload your ad creative (an image or a video) and get your copy.

## 4. Save your workspace

ChatGPT forgets files between chats. At the end, it gives you a **workspace zip**. Download it.

Next time, upload **both** zips (the AI Ad Copywriter zip and your workspace zip), paste the kickoff prompt, and it skips straight to writing.
