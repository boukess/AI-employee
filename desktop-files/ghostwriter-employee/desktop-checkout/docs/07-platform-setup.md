# Choose your setup

You do not need to code. The writing workflow can run from one text attachment.

## Claude or ChatGPT in a normal conversation

1. Download the zip from the lesson.
2. Try attaching it and send: **Go. Read the AI Ghostwriter Employee instructions and start.**
3. If the chat cannot open it, unzip it on your device. On many computers, double-clicking does this; on Windows, use **Extract All** if needed. Attach **GHOSTWRITER.txt** from inside the folder and send **Go**. If you cannot attach a file, paste its text.

The TXT file contains the complete operating manual and templates, so you do not need to upload every file. The zip's acceptance and extraction depend on your account and chat tools. Claude's documented upload types include TXT; ZIP is not listed. This is why the one-file route is included. [Claude file upload documentation](https://support.claude.com/en/articles/8241126-upload-files-to-claude).

If you want a reusable project, add GHOSTWRITER.txt to a project and put this in the project's instructions: “Use the attached GHOSTWRITER.txt as my ghostwriter workflow. When I say go, start or resume. Read MY-GHOSTWRITER-MEMORY.txt first when supplied.” Add your latest memory file after working together. Project context and local folder access are different capabilities. [ChatGPT projects documentation](https://learn.chatgpt.com/docs/projects?surface=app).

## A desktop assistant with folder access, Claude Code, or Codex

Unzip the download and open the **AI Ghostwriter Employee** folder in the assistant. Say **Go**. `CLAUDE.md` and `AGENTS.md` provide the local entry points. Grant relevant folder or app access through your host only when needed. The employee uses available tools and stores work in `workspace/`.

A code sandbox that can unzip a file does not automatically have access to your computer. The package cannot unlock hidden conversation history, connectors, computer use, or Playwright. If tools are absent, the employee uses the files and text you share and suggests the easiest next source.

## Next time

Stay in the same project where practical. For a new chat, attach **GHOSTWRITER.txt** and your latest **MY-GHOSTWRITER-MEMORY.txt**, then say **Continue**. The save contains your voice notes and selected examples. Keep the private save for yourself; the starter zip is the one to share.

## If it gets stuck

| What happened | What to do |
|---|---|
| “I can't read the zip” | Unzip and attach GHOSTWRITER.txt |
| It summarizes the file | Say “Follow these as my working instructions and begin now” |
| It cannot browse | Give one link's text, a few writing samples, or answer its short voice question |
| A private post will not open | Paste only your own text from it |
| It asks you to install software | Say “Use the text-only workflow for now” |
| It sounds generic | Rewrite the weakest sentence and say “Learn from this correction” |
| It forgot your profile | Attach the latest memory file and say “Continue” |

Documentation checked October 13, 2026. Interfaces, tools and plan availability can change. These setup routes are designed to degrade gracefully; check the release test report for what was actually exercised.
