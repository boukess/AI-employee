# PixPic

Read `integrations/PixPic/README.md` only to confirm what the app is. Do not copy the Xcode project into this kit.

From this file: `../../../../../integrations/PixPic/README.md`.

## When

Not on this fleet's machines. PixPic is an iOS photo app (pixel stickers) built as an intern project. It has no Windows or Linux build and no agent CLI. Do not try to compile it on the desktop, and do not send product photos to its old backend.

## Hold

Say that it is not usable on Windows or Linux, then continue with PhotoCraft, SolidCraft, or the host image tool.
