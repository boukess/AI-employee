# Sessions

When you run the council from a local folder (Claude Code, Cowork or Codex), every meeting is saved here, one file per meeting:

```
sessions/2026-09-28-raise-coaching-price.md
sessions/2026-10-31-board-review-october.md
```

Each file holds the date, the format, who was seated, your question, and the full meeting: every advisor's answer and the Chair's call.

## Use them

- **"What did we decide about pricing?"** The AI searches these files and answers with dates.
- **"Board review"** reads last month's review and checks whether you did last month's priorities.
- **"Follow up with Chesky"** picks up from the latest meeting.
- **"Log outcome: I raised the price and 4 of 5 new clients paid it."** Adds what happened to the matching meeting, so the council can see what worked.

## Good to know

- Nothing is ever overwritten. Two meetings on the same topic on the same day get `-2` on the end.
- These files hold your business details. Treat the folder like your financial records.
- Web projects (Claude or ChatGPT) do not save files here. Your chats stay in the project's chat list.
