# Compositor

Read `integrations/Compositor/README.md` if you need the upstream limits. Do not copy the Xcode project into this kit.

From this file: `../../../../../integrations/Compositor/README.md`.

## When

Not on this fleet's machines. Compositor requires macOS 26 or later on Apple silicon. The Product Photography Employee runs on a Windows desktop and is also used from Linux. Do not launch it, do not look for an unofficial Windows or Linux port as if it were this submodule, and do not tell the member a `.comp` file was opened in Compositor.

If the member is on a Mac that meets the requirement, they can install the upstream release themselves. That is outside this employee's Windows and Linux workflow.

## Hold

Say that the tool is not usable here, then continue with PhotoCraft, SolidCraft, or the host image tool.
