# A worked example of the process

This is a walkthrough, not the current member's identity or voice. Do not copy it into a member's profile.

The founder's local proof run started with an empty employee folder. Relevant project files and a narrow search of available memory identified Kyle Herbel and AI Employee Lab. Public pages corroborated the business, and local video transcripts supplied wording for a starter profile.

One promising folder contained a corpus attributed to a different creator. It was excluded. Older memory also pointed to a long-form transcript folder that no longer existed at its recorded path; it was logged as unavailable instead of treated as read.

The useful evidence consisted primarily of short spoken explanations plus Kyle's direct project brief. That supported observations about input/action/output explanations, connected clauses, concrete next steps, and beginner guidance. It did not establish a complete email, article, or narrative voice. Existing AI-generated brand notes were treated as context rather than independent originals.

The proof run produced a source ledger, a provisional voice profile, a portable memory file, and email/article/story drafts. Source bookkeeping and editorial checks were exercised locally. Kyle's personal source text and drafts are kept outside the community zip. The writing remains a first calibration pass until Kyle reviews it.

For a new member, the process starts with their own evidence and a short draft. A large word count is not a substitute for verified authorship, useful source variety, and the member's corrections.
