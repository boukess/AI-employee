# take-one

Read `INTEGRATIONS.md` in this kit, then read and follow the upstream skill in place. Do not copy it into this kit.

Upstream skill: `integrations/take-one/SKILL.md`

From this file that path is `../../../../../integrations/take-one/SKILL.md`.

## When

The member wants a launch film, ad, explainer, or music video made as code, from a short brief, with a review room for notes. Do not use it for "Edit my video" on a talking-head clip. That job stays on the desktop pack in free Resolve mode.

## Run

Check the submodule out, then run `bash integrations/take-one/scripts/doctor.sh`. The skill's own README names Node 18 or newer, Google Chrome, and ffmpeg. Upstream has been run on macOS only. On Windows, treat the tool as unproven until doctor.sh passes.

The code-only path is free and is the default on this fleet. Picture models, video models, ElevenLabs, and Suno are optional. Ask before any paid call, with the price, and do not put a key in this kit.

## Hold

Draft and render locally. Do not publish or send the film unless the member names that action.
