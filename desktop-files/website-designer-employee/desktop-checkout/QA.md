## Independent member trial

A separate agent received the folder and a fictional beginner pottery-studio brief. It followed START-HERE → AGENTS → the employee instructions and produced a complete local site in cream, clay, and charcoal. It used an original labeled ceramic illustration, working workshop-section links, honest pending dates/prices, and all five project records. It did not copy the Lab's dark technology direction or invent bookings, testimonials, or photography.

The trial's build, HTTP delivery, internal anchors, JavaScript syntax, public-folder isolation, and simulated motion-state checks passed. A separate reviewer inspected the desktop and 390px compositions, confirmed no horizontal overflow, and exercised the workshop link. Full live motion, reduced motion, keyboard and touch acceptance were not repeated on this disposable trial. It was not published.

Minor instruction ambiguities found by the trial were clarified: gentle motion is appropriate for calm briefs; real section links can be valid actions; unavailable visual tools must be reported; review outcomes and methods are recorded separately.

## Inherited checks and boundaries

The five library scenes retain the previous library release's desktop/phone, controls, reduced-motion, and original-asset work. The cinematic starter derives from the polished AI Employee Lab website, whose original review covered chapter transitions, pause/resume, keyboard focus, fallback, reduced motion, and short phones. The generic adaptation preserves that implementation but changes content and identity. Those inherited checks do not replace review of a member's own altered website.

Not claimed: universal Claude Code/Codex version compatibility, automatic access to private chats, deployment from every host, field performance scores, conversion results, real forms/checkout/booking, or guaranteed visual quality without iteration. The direct-folder instructions and independent coding-agent trial were exercised; this release was not separately installed and run inside every supported app/version. Optional MCP registration commands are documented, not automatically installed.

The public Lab example is a separate project and source download. Skool lesson and attachment publication is tracked by the module's delivery record outside this reusable kit.
