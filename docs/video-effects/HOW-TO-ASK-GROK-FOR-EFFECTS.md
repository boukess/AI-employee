# How to Ask Grok for Effects

You do not need to learn any settings. Talk to Grok Bot like you would brief an editor.

Every prompt that needs a clip has a `[your video]` spot. Attach your video in chat (or drop the file into this conversation) and Grok fills in the path for you.

## 1. Name the effect and the moment

Point at the moment by time or by the words you say. Words work better, because the graphics land exactly when you say them.

> Add the checklist effect to [your video] where I say "all you need to do is".

> Add the orbit effect to [your video] from 0:04 to 0:10.

## 2. Give it the content

Tell Grok the words, steps, numbers or images to use. If you leave them out, it writes them from what you say in the video.

> Chart grow when I say "my views tripled", with the label +312%.

## 3. Not sure which effect fits?

> Which effects would work on [your video]?

Grok reads your transcript and suggests effects for specific sentences.

## 4. Adjust it like you would with an editor

- "Make the text bigger and move it higher."
- "Change the yellow to my brand blue, #2D6BFF."
- "Start it half a second earlier."
- "Render a quick draft first so I can check it."

## Captions

Every effect adds word-by-word captions. There are 6 looks: pop, caps, two-tier, serif, tracked and box.

> Use the box caption style, a little lower on the screen.

> Turn the captions off for this one.

If a name comes out wrong, tell Grok the right spelling once:

> The captions say "cloud code". It should be "Claude Code".

## Several effects in one video

> Add 3 effects to [your video] and stitch them into one finished video.

Grok plans which effect goes on which sentence, renders each one, adds captions to the parts in between and splices everything into one MP4 with your original audio running underneath.

## What looks good

- One effect per idea, then let the plain footage breathe for a few seconds.
- 2 to 4 effects in a 30 to 60 second reel is plenty.
- Use the same caption style across the whole video.

## Who to ask

- **Grok Bot** (this chat): attach a video and use the prompts above.
- **Social Media Employee**: use the same language when the finished clip is meant for a post queue.
