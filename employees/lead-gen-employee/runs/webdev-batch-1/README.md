### What you need to do (≈5 minutes)
1. HighLevel → **Settings → Email Services → Dedicated Domain** (may be labeled "Dedicated Domain and IP") → **Add Domain**.
2. Enter `mail.frbouke.com` → **Add & Verify**.
3. HighLevel shows a list of DNS records. SPF, MX, CNAME and DMARC above are already in place. Copy the **DKIM TXT record** (host looks like `xxx._domainkey.mail` and the value starts `k=rsa; p=...`) and either send it to me to add, or add it yourself in Vercel → frbouke.com → DNS Records → Add (Type TXT, Name = the host without `.frbouke.com`).
   If HighLevel shows any value different from the table above (e.g. a different CNAME target), tell me and I'll match it exactly.
4. Click **Verify** (DNS can take up to an hour; usually minutes).
5. On the verified domain, open the ⋮ menu → **Set Headers**: From Name `Michael, BOUKE LLC`, From Email e.g. `michael@mail.frbouke.com`. Set Reply-To to an inbox you actually read (replies to the mail. subdomain are not stored anywhere by default).
6. Send one test email to yourself and click the unsubscribe link to confirm it works.

### How the leads were found and checked
- Source: OpenStreetMap business listings (Geofabrik extracts, data © OpenStreetMap contributors, ODbL) that publish both an email and a website. Every lead row links the listing (`osm_listing`) and the page the email came from (`email_source_url`). No emails or names were guessed or invented.
- Each business's website was fetched live on 2026-11-04 and the opener only states something actually observed (no mobile viewport, a free builder address like wixsite/square.site, the website link pointing to Facebook/Instagram, an old © year, etc.). Sites that were down, parked, or behind a bot check were dropped.
- Email domain checked for real mail records (Google DNS). Excluded: chains/brands, government, NGOs, schools, competitors (web/design/marketing/IT businesses), sensitive categories, personal-looking addresses outside the US, and any page saying it doesn't want unsolicited email.
- Deduped by email and by website domain, and against every existing HighLevel contact (30 at import time, none overlapping).
