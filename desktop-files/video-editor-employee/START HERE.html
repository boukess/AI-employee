1 Get your workspace ready

Keep this folder

Extract the ZIP into Documents or another permanent location. Keep the files together. Your AI will use this folder for every video.

Have these apps installed

DaVinci Resolve Studio 21.1+, Node.js 22+, and Python 3.12. The AI can guide installation.

Open Resolve. In Preferences → System → General, set External scripting to Local.

macOS tested. Windows setup is included but has not been rendered on Windows. Apps and AI account access are separate from this download. Allow space for temporary renders; 20 GB free is a practical starting allowance.
