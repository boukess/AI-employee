How do I keep my progress?

Say “Save my progress.” Keep the MY-GHOSTWRITER-MEMORY.txt file or text it gives you. In a new chat, add it alongside GHOSTWRITER.txt and say “Continue.” Keep this personal save for yourself.

What if I use a local project folder?

Open the unzipped AI Ghostwriter Employee folder in Claude Code, Codex, or an assistant with folder access. Say “Go.” Its instructions are in AGENTS.md and CLAUDE.md, and your work is saved in workspace/ when file writing is available.

Can it use my computer and old conversations?

Only when your assistant actually has that access. It uses relevant available tools and memory, then gives you an easy alternative for anything it cannot open. The download itself does not install tools or grant access. It works during your active conversation.
