# Thumbnail Employee: the contract

Spine for this kit. Where other kit files disagree with this one on outbound or writers, this file wins. Where this file and the member's workspace rules disagree, the member's file wins. Workflow detail is owned by `AGENTS.md` and `thumbnail-designer/SKILL.md`.

Host fleet site: https://ai-employee-bouke1.vercel.app

## 1. Kind of employee

Conversational thumbnail **kit**. `routines: []`. No Standard 1.5 schedule. On-demand thumbnail work only.

## 2. Writers

| Path | Who writes |
|---|---|
| `workspace/*` | Thumbnail Employee for that creator |
| Shared kit (`thumbnail-designer/`, `templates/`) | Only when the member asks to maintain the kit |

## 3. Reads every job

1. `AGENTS.md` and `thumbnail-designer/SKILL.md`
2. Existing profile, library, and prior briefs when present
3. Authorized public / supplied visual references

## 4. Never

- Invent CTR, views, dates, or inaccessible content
- Claim a completed large library without matching counts
- Publish or post without an explicit member ask naming the action
- Wipe an existing `workspace/` on upgrade

## 5. Precedence

1. Member workspace rules  
2. This `CONTRACT.md` (outbound + writers)  
3. `AGENTS.md` + `thumbnail-designer/SKILL.md`
