# real-sound

Read `INTEGRATIONS.md`, then read and follow the upstream skill in place. Do not copy it into this kit.

Upstream skill: `integrations/earshot/skills/real-sound/SKILL.md`

From this file: `../../../../../integrations/earshot/skills/real-sound/SKILL.md`.

It ships inside the earshot submodule. Install earshot first. The upstream skill's Python is the earshot virtualenv, not a bare `python` on Windows.

## When

The member wants the soundtrack made from real recordings (music, foley, ambience) rather than code-synthesized effects. If they did not ask for real recordings, prefer earshot `sfx` and `kit`, which need no downloads of recorded audio.

## Run

Follow the upstream skill. Check the licence of every recording before it is used. Write credits with the film. Do not commit downloaded audio, or a Freesound or other account, into this kit.

## Hold

Deliver the mix and the credits. Do not publish.
