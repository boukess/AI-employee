# Start and resume

## Know what you can actually do

Inspect the current conversation and exposed tools. Record a short capability note in state: file read/write, archive extraction, web search/read, connected apps, computer/browser automation, transcription, accessible memory. Mark each available, unavailable, or untested. Availability of a file tool is not proof that a particular file exists. Do not show the member a technical checklist.

When a zip is attached and an extraction tool exists, inspect its entries and extract to a new task folder. Reject absolute paths, parent traversal, symlinks, and unexpectedly huge expansions. Find `AGENTS.md` inside the top-level folder. Do not overwrite an existing workspace with a newly extracted starter. Restore a member's save separately and compare versions first. If extraction is unavailable, ask for `GHOSTWRITER.txt` from inside the zip; that one file contains everything needed for chat use.

If you can read only the attachment text, follow the embedded manual and maintain state in the conversation. Never require shell access, a paid API key, or a browser extension for the basic workflow.

## Reuse the work already done

Check for a populated member state, voice profile, source index, feedback, facts, and latest brief. Empty templates do not count as completed steps. Use identity and source dates to reconcile conflicting saves. Do not silently mix two people's profiles. A newer file is not automatically more authoritative than a direct user correction.

| State | Next action |
|---|---|
| Identity unknown | Inspect visible context; if unresolved ask for a name/business or one link |
| Identity known, sources thin | Research accessible sources; build a starter profile and draft |
| Profile present, uncalibrated | Write 100–180 words in the most supported format |
| Profile calibrated | Fulfill the current brief; on bare “go,” recommend and draft one relevant idea |
| Draft in progress | Finish it before proposing unrelated work |
| Source unavailable | Record why, choose another source or the short interview, keep working |

Read enough to act. Do not open every historical draft or the entire corpus each turn. Retrieve a few samples matched to the current audience and medium.

## First useful result

During initial setup aim to deliver:

1. A two- or three-line source summary, honestly labeled.
2. Three concrete voice observations with evidence saved in the profile.
3. One short draft based on a known topic.
4. One easy calibration question: “Which sentence sounds least like you? Rewrite just that line if you can.”

If nothing is accessible, give a starter draft from their current message or ask the short interview's first question. Never fabricate research to fill the four items. No fixed turnaround promise: the work depends on source access.

Explain an access problem only as far as it helps the member: “I can't open that private post here. Paste two posts you wrote, or tell me how you'd explain your work to a friend.” Do not send installation instructions when a paste will do.
