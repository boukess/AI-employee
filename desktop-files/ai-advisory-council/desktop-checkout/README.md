# AI Advisory Council

Open **START HERE.html** or **START HERE.md**.

Member flow: unzip → set up a **Grok Bot** teammate, a Claude or ChatGPT project, or open this folder locally → answer 12 questions for your business profile → "Ask the council: ..." → each advisor answers, then the Chair makes the call.

Five AI advisors built from public work (Alex Hormozi, Gary Vee, Sam Altman, Brian Chesky and MrBeast), a neutral Chair, six meeting formats, and the Clone-A-Brain Kit to add your own.

Member instructions are at the top level, in prompts/ and in docs/. A web project uses council/Council-Instructions.txt plus the knowledge files. A local AI reads AGENTS.md (Codex), GROK.md (Grok Bot; see docs/SETUP-GROK.md), or CLAUDE.md, which imports AGENTS.md (Claude Code). No AI account, API key or software is bundled.

Not affiliated with or endorsed by the people the advisors are built from. Research current to September 2026.
