# Motion reference implementation

Scenes.tsx shows the timing, geometry, asset framing and animation used for the accepted editing format. It has been sanitized: no original speaker frame, private job or raw input is included. It is about Claude Code + Resolve only. Reuse its techniques, not its topic, in unrelated videos.

Preview the silent graphics sampler after setup:

`node node_modules/@remotion/cli/remotion-cli.js studio examples/index.tsx --props=examples/props.json`

The included props are for preview only, with no presenter or dialogue. For an actual member video, author that job's plan.json and motion/Scenes.tsx using the current transcript. Do not export this sampler as their edit.
