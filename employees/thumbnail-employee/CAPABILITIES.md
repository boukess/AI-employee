# Thumbnail Employee: capabilities

Thin map for the fleet index. Operating detail lives in `AGENTS.md` and `thumbnail-designer/SKILL.md`.

| Capability | Route |
|---|---|
| `file.read` | Kit skill, templates, member workspace |
| `file.write` | `workspace/` profile, library, briefs, outputs |

| `image.generate` | Host built-in image tools when available |
