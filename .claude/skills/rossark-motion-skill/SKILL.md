# rossark-motion-skill

Read `INTEGRATIONS.md`, then read and follow the upstream skill in place. Do not copy it into this kit.

Upstream skill: `integrations/rossark-motion-skill/SKILL.md`

From this file: `../../../../../integrations/rossark-motion-skill/SKILL.md`.

## When

The member wants a drawing, logo, mascot, icon, chart, or illustrated scene to move as if it is alive. This is not a talking-head editor and not a full film renderer by itself.

## Run

On the first job, copy the upstream `MOTION.md` next to the art and fill in its project notes. Templates live in `templates/react-native/` and `templates/swiftui/`. The Swift offline renderer in the upstream README is macOS only. Do not claim that renderer ran on Windows. The method also applies on the web where that stack exists.

## Hold

Leave the motion in the member's project. Do not publish it unless the member names that action.
