# Video Editor Employee: capabilities

Thin map for the fleet index. Operating detail lives in `AGENTS.md` and `INTEGRATIONS.md`.

| Capability | Route |
|---|---|
| `file.read` | This kit, `INTEGRATIONS.md`, upstream skills in `integrations/` |
| `file.write` | Desktop pack `jobs/` and `exports/`, or a project folder the member names |
| `video.edit.talking_head` | IBP_Desktop pack, free Resolve mode, FFmpeg, FCPXML, Remotion |
| `video.render.code` | explainroo, huashu-motion, take-one, argo, reanimate, rossark-motion-skill, as `INTEGRATIONS.md` chooses |
| `video.qa` | video-director scripts, earshot measurements |
| `video.edit.concat` | Separate AGPL Concat process. Not vendored. |
| `outbound.send` / `publish` | **Never**, unless the member explicitly asks |

## Harnesses

Grok Bot on IBP_Desktop is the fleet path for the desktop pack. Codex and Claude Code can follow the same files when the folder is the workspace. A tool that is not installed is needs install, not a silent substitute.

## Platforms

Windows desktop is the member machine. Linux is where the repository checks run. macOS-only steps (take-one's proven path, huashu-motion's tested path, rossark's Swift renderer) stay needs install until their doctor passes on Windows.
