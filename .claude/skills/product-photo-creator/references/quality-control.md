# Product fidelity and delivery

## Before generation

Inspect the actual image, not only the filename. Identify the hero item and note: silhouette/proportions, dominant colors, material finish, defining components, brand marks, readable label text, and hidden or blurry areas. Keep notes concise. A transparent product, tiny jewelry, or complex packaging may need an additional close-up; do not demand multiple photos for every item.

If the source is blurry or partially obscured, decide whether a supported view can still be useful. Ask for another image when the missing detail is necessary. Never invent exact wording, backside details, dosage, nutrition values, or certifications. A typed label can confirm wording but cannot establish its exact visual layout.

## Inspect the result

View the returned output. Compare the product region with the original, preferably at a detail scale as well as full frame when viewing tools allow. Check:

1. **Identity:** same SKU, item count, shape, proportions, closure, attachments, seams, and functional features.
2. **Markings:** same visible logo, wording, numerals, units, layout, and print placement. Flag small unreadable text as unverified; OCR alone does not establish a visual match.
3. **Material and color:** plausible surface, no material substitution, no obvious hue shift or loss of fabric/food texture.
4. **Scene physics:** consistent light, perspective, grounding, shadows, reflection, and transparency; no fused edges or floating support.
5. **Composition:** requested framing, entire item when required, no unwanted extras or cropped features, useful focus.
6. **Delivery:** actual output exists; report file type, dimensions, transparency, or ratio only when verified. “Requested square” is distinct from “verified 1024 × 1024.”

Do not manufacture numeric confidence or assert “100% accurate.” A visible pass means no issue was found in the inspected areas, not a guarantee of identity or listing compliance.

## Correction budget and stopping

A first shot includes at most one targeted corrective generation unless the user requests more. Prioritize identity and label issues over atmosphere. Inspect the correction again. Stop repeated generation when the same critical feature keeps changing or the tool hits a limit. Explain the specific remaining problem and the best next input or edit path.

If the output cannot be viewed, deliver it as **not visually checked** and say which comparison remains. Do not claim a review took place based on the tool's success message. If generation fails, say no image was created and retain the prompt for recovery.

## Exact-label or exact-product requests

Generative editing is not a guarantee of pixel preservation. Explain the limitation briefly when exactness is requested or an actual defect appears. If a suitable tool is available, use a preservation/compositing workflow that retains the original product pixels and edits the background; verify the edge, shadow, and product region. Follow that tool's capabilities and instructions. Never call a generative mask a guaranteed pixel lock.

If preservation tools are unavailable, offer a background-only generation plus compositing handoff, or a faithful generative draft clearly identified as such. Get the user's choice when it changes the promised result. A higher-resolution straight-on product image and label artwork can improve the process but do not guarantee generated lettering. Do not keep retrying tiny text indefinitely.

## Delivery language

Show the image first. Keep text short, for example: “Here is the clean studio version. I kept the original viewpoint and used a soft neutral backdrop.” Mention a real limitation when present: “The small dosage line changed; this version needs that corrected before use.” Avoid a generic warning block on every shot.

Provide a download link only if one exists. In a writable workspace, include the saved image and prompt paths. Retain an approval-pending status for any unresolved critical fidelity issue. An attractive image with a changed label does not pass the product check.
