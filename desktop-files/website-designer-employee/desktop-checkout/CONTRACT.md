# Website Designer Employee: the contract

Spine for this kit. Where other kit files disagree with this one on outbound or writers, this file wins. Where this file and the member's workspace rules disagree, the member's file wins. Workflow detail is owned by `AGENTS.md` and `scene-website-director/SKILL.md`.

Host fleet site: https://ai-employee-bouke1.vercel.app

## 1. Kind of employee

Conversational design/build **kit**. `routines: []`. No Standard 1.5 schedule. On-demand website work only.

## 2. Writers

| Path | Who writes |
|---|---|
| `member-projects/<brand>/*` | SCENE for that brand's site and project records |
| Shared kit (`library/`, `starters/`, skill) | Only when the member asks to maintain the kit |

## 3. Reads every build or revision

1. `AGENTS.md` and `scene-website-director/SKILL.md`
2. Existing member `BRAND-BRIEF.md`, `DESIGN-BRIEF.md`, `ASSET-MANIFEST.md`, `QA.md`, `PROJECT-STATUS.md` when present
3. Authorized public sources / supplied assets

## 4. Never

- Invent proof, testimonials, metrics, case studies, logos, or contact emails
- Simulate successful form/booking/checkout submissions
- Spawn review/critique agents
- Publish, send, or purchase hosting/domains without an explicit member ask naming the action
- Wipe an existing member project on upgrade

## 5. Precedence

1. Member workspace rules  
2. This `CONTRACT.md` (outbound + writers)  
3. `AGENTS.md` + `scene-website-director/SKILL.md`  
4. `ROLE.md` / `CAPABILITIES.md` / `GROK.md`
